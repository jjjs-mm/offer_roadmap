# 书单（Agent Infra 方向）

> **四个月最多读 2 本书。** 书的密度太低、见效太慢，主力资源应该是论文、博客和源码。
> 这份清单的正确用法是**查阅式阅读**：需要哪一章读哪一章，不追求通读。

## 一、四个月内值得投入的（最多选两本）

| 书 | 为什么读 | 怎么读 |
| --- | --- | --- |
| **《数据密集型应用系统设计》（DDIA）** | agent infra 的系统设计题（状态存储、一致性、分区、故障处理）答案都在这本里。你的后端优势要靠它变成表达能力 | 挑读第 1、5、6、7、9 章。**性价比最高的一本** |
| **《Build a Large Language Model (from Scratch)》** Sebastian Raschka | 用代码把 transformer / attention / KV cache 走一遍，比看十篇博客更能把原理钉死 | 跟着敲代码，重点是 attention 与生成部分，训练章节可略 |
| **《AI Engineering》** Chip Huyen | 覆盖 eval、RAG、推理优化、成本控制的工程视角，和你的项目二高度重合 | 挑读 eval 与推理优化章节 |

**如果只读一本：DDIA。** 它对系统设计面试的直接帮助最大，而且不会过时。

## 二、按需查阅（不通读）

| 书 | 什么时候翻 |
| --- | --- |
| 《深入理解 Java 虚拟机》 | 面 Java 八股前突击 GC 与内存模型章节 |
| 《Fluent Python》 | 写 Python 遇到不地道的写法时查，重点：装饰器、异步、类型 |
| 《Kubernetes in Action》 | 项目一部署遇到概念不清时查 |
| 《深入理解计算机系统》（CSAPP） | 补 Linux 进程、内存、IO 的基础概念时查第 8–10 章 |
| 《Linux 性能优化实战》/ 极客时间 | 压测发现瓶颈但定位不出来时查 |
| 《动手学深度学习》（d2l） | 需要补 PyTorch 基本操作时查 |

## 三、不建议现在读

- **各类「大模型应用开发实战」类书籍**：内容基本是框架 API 教程，半年就过时，而且面试不加分。
- **深度学习理论教材**（花书、Bishop）：与 infra 岗关联度低，时间不够。
- **算法书**（《算法导论》）：直接刷题 + 看题解更高效，导论只在某个专题彻底不懂时查。

## 四、时间分配提醒

看书的时间**上限是每天 1 小时**，且应该挤在「读论文/源码」的那个时段里，不能占用项目开发时间。

四个月结束时，你的说服力来自三个项目的数字和 merged PR，不是读过几本书。**如果某周项目进度落后，第一个该砍的就是读书。**
