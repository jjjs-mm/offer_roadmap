## 刷题原则

1. **20 分钟没思路就看题解，看完立刻自己重写一遍。** 硬想两小时的收益远低于「看懂 + 复现 + 隔周重做」。
2. **同类题连着刷。** 滑动窗口一次刷 10 题，比每天换专题有效得多——你要建立的是模式识别，不是题目记忆。
3. **必须口述思路后再写代码。** 面试是边说边写，只会闷头写代码的人在面试里会卡住。
4. **错题隔一周重做。** 记进[错题本](#错题本)，重做通过才划掉。
5. **手写，不靠 IDE 补全。** 很多面试是共享文档裸写，没有语法高亮和自动补全。
6. **语言选 Python。** 面试写得快，且和你四个月的技术栈一致；Java 保留作为后端岗备用。
7. **不以 AC 次数冒充掌握。** 同一道题的首次学习与一周后独立复刷分别记一次“题次”，但“新题数”只记一次。

## 每个模块怎么练

每周只学一个主模块，按固定节奏形成模式识别：

| 日期 | 任务 | 验收标准 |
| --- | --- | --- |
| 周一 | 学模板 + 2 道基础题 | 能口述「什么时候识别出这个模型」 |
| 周二–周四 | 每天 2 道新题 | 20 分钟无思路就看题解，关掉题解立即重写 |
| 周五 | 2 道中等题限时训练 | 每题 25 分钟，先说思路和复杂度再写 |
| 周六 | 2 道新题 + 本周错题重写 | 不看历史代码 |
| 周日 | 45 分钟模拟面试（2 题）+ 周复盘 | 裸写、口述、自己补测试用例 |

一周约 **10 道新题 + 4 次复刷/模拟**。忙到只能保底时，不要随便挑题：每天复刷 1 道本模块核心题，保持手感。

每道题要过三关：

1. **识别**：看到题能说出为什么属于这个模块
2. **实现**：20–25 分钟内独立写完
3. **解释**：能口述不变量、复杂度和一个容易错的边界

三关都过才算掌握；只看懂题解不算。

## Agent 岗高频非标准手撕题

这些不在标准题库里，但 agent / infra 岗面试常出，**第 4 月前每道都要能白纸写出来**。与 [../docs/interview.md](../docs/interview.md) 的手撕清单同步。

- [ ] 带 TTL 的 LRU 缓存（哈希 + 双向链表 + 惰性过期）
- [ ] 令牌桶限流器（含并发安全）
- [ ] 滑动窗口限流器（分布式版本怎么改也要想清楚）
- [ ] 简易线程池 / 协程池（含任务队列与优雅关闭）
- [ ] 带并发上限 + 重试 + 超时的批量任务执行器（`asyncio.Semaphore`）
- [ ] 按 token 预算裁剪消息历史（滑窗版 + 保留 system prompt 与最近轮次）
- [ ] 用 numpy 实现 attention 前向计算（含 mask 与 softmax 数值稳定）
- [ ] 暴力向量检索：余弦相似度 + 堆取 Top-K
- [ ] 解析嵌套 JSON 中的 tool call 并做参数类型校验
- [ ] 生产者-消费者模型（多生产者多消费者 + 有界队列）
- [ ] 实现指数退避重试装饰器（含抖动 jitter）
- [ ] 大文件按行流式处理并统计 Top-K 频次（考察内存约束下的思路）
