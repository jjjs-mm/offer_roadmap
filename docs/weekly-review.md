> 每周日晚上花 30 分钟填完。**复盘的唯一目的是发现偏离并纠正**，不是记录情绪。

## 周复盘模板

复制以下模板到[周复盘记录](#周复盘记录)追加使用。

```markdown
### W__（MM/DD – MM/DD）

**本周 roadmap 目标**：（抄自 roadmap.md 的对应周）

**实际产出**
- 项目：____（具体到「实现了什么 / 测出了什么数字」，不写「推进了一些」）
- LeetCode：__ 题（累计 __）
- 博客 / 笔记：____
- 开源：____

**投递与面试**
- 新投递：__ 家
- 新增面试邀约：__ 个
- 完成面试：__ 场（真题已回填 interview.md：是 / 否）

**卡点**
- ____（写清是「技术不会」还是「时间不够」还是「方向错了」，三者的解法完全不同）

**下周调整**
- ____（必须是可执行的加减法，不是决心）

**本周状态**：投入时长 __ h / 精力评分 __ /5
```

## 投递追踪表

**填写要求**：投出去当天就记，不要攒。用的哪版简历一定要记，方便回头看哪版转化率高。

| 日期 | 公司 | 部门/团队 | 岗位 | 渠道 | 简历版本 | 状态 | 备注 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| | | | | 内推/官网/BOSS | v_ | 已投 | |

**状态取值**：已投 → 简历筛选中 → 笔试 → 一面 → 二面 → 三面 → HR 面 → offer / 挂 / 无响应（两周无响应记为无响应）

**渠道优先级**：内推 > 官网 > BOSS/牛客等平台。同一家公司优先内推，内推找不到人再官网投。

| 公司 | 当前轮次 | 上次面试日期 | 面试官反馈 | 下一步 / 待跟进 | 截止提醒 |
| --- | --- | --- | --- | --- | --- |

**跟进规则**：面试后一周无消息主动问 HR 一次；两周无消息记为默认挂，不要在心理上占用名额。

## 月度能力自评

每月末重评一次（0 = 没碰过，5 = 能独立设计并讲清权衡），对照 [roadmap.md](roadmap.md) 的目标值看差距。

| 能力项 | 8/20 起点 | 9 月末 | 10 月末 | 11 月末 | 12 月末 | 目标 |
| --- | --- | --- | --- | --- | --- | --- |
| Java / 分布式后端 | 3 | | | | | 4 |
| Python 异步工程化 | 1 | | | | | 4 |
| LLM API 与 tool calling | 1 | | | | | 4 |
| Agent 架构与 context engineering | 0 | | | | | 4 |
| Docker / K8s / 沙箱隔离 | 1 | | | | | 3.5 |
| 推理引擎（vLLM / SGLang） | 0 | | | | | 3 |
| Eval 与 benchmark 设计 | 0 | | | | | 3.5 |
| 可观测性（OTel / trace） | 1 | | | | | 3 |
| 算法（LeetCode） | 2 | | | | | 4 |

**评分要诚实。** 虚高的自评会让你跳过该补的短板，代价是在面试里被击穿。
