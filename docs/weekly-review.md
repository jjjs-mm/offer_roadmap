## 投递追踪表

**填写要求**：投出去当天就记，不要攒。用的哪版简历一定要记，方便回头看哪版转化率高。

| 日期 | 公司 | 部门/团队 | 岗位 | 渠道 | 简历版本 | 状态 | 备注 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| | | | | 内推/官网/BOSS | v_ | 已投 | |

**状态取值**：已投 → 简历筛选中 → 笔试 → 一面 → 二面 → 三面 → HR 面 → offer / 挂 / 无响应（两周无响应记为无响应）

**渠道优先级**：内推 > 官网 > BOSS/牛客等平台。同一家公司优先内推，内推找不到人再官网投。

### 阶段一：日常实习目标清单（2026-10 起投，南京优先）

**目标：12 月初入职。** 岗位定义要放宽——云原生 / 平台 / 后端都算，只要技术含量真实。判断标准是那三个问题：mentor 是谁、代码进不进主干、有没有 GPU 和真实流量。

| 优先级 | 类型 | 公司 / 团队 | 岗位 | 内推资源 | 状态 |
| --- | --- | --- | --- | --- | --- |
| 1 | 南京 · LLM/agent 相关 | | | | |
| 1 | 南京 · 行业大模型落地（运营商/电力/金融/通信） | | | | |
| 2 | 南京 · 大厂研发中心平台/后端岗 | | | | |
| 3 | **远程**（agent 创业公司，普遍接受远程） | | | | |
| 4 | 苏州（高铁约 1h） | | | | |
| 4 | 上海（高铁约 1.5h） | | | | |

**入职前必须确认**：能否在 2027 年 2 月底结束（有些岗位要求六个月以上，会直接压掉暑期实习的投递时间）。

### 阶段二：暑期实习目标清单（2027-02 底启用，杭州主投）

**暑期实习才是决胜局**，它直连转正与秋招。正式工作倾向杭州，因此以杭州为主战场；但不设为唯一城市，避免错过明显更优的团队。建议投递分布：**杭州 60% / 上海 15% / 北京 15% / 深圳及其他 10%**。

**投递时机**：字节、腾讯、美团、阿里等通常在 2 月 20 日 – 3 月 10 日陆续开放。**有一段日常实习经历就「开启即投」**，不要拖到 4 月——2 月底那批的 HC 和捞人意愿远高于 4 月。

## 月度能力自评

每月末重评一次（0 = 没碰过，5 = 能独立设计并讲清权衡），对照 [roadmap.md](roadmap.md) 的目标值看差距。

| 能力项 | 8/20 起点 | 9 月末 | 10 月末 | 11 月末 | 12 月末 | 目标 |
| --- | --- | --- | --- | --- | --- | --- |
| Java / 分布式后端 | 3 | | | | | 4 |
| Python 异步工程化 | 1 | | | | | 4 |
| LLM API 与 tool calling | 1 | | | | | 4 |
| Agent 架构与 context engineering | 0 | | | | | 4 |
| Docker / K8s / 沙箱隔离 | 1 | | | | | 3.5 |
| 推理引擎（vLLM / SGLang） | 0 | | | | | 3 |
| Eval 与 benchmark 设计 | 0 | | | | | 3.5 |
| 可观测性（OTel / trace） | 1 | | | | | 3 |
| 算法（LeetCode） | 2 | | | | | 4 |

**评分要诚实。** 虚高的自评会让你跳过该补的短板，代价是在面试里被击穿。

## 关键指标看板

一眼看全局，每周更新。

| 指标 | 目标 | 截止时间 | 当前 |
| --- | --- | --- | --- |
| **日常实习 offer** | **1** | **11 月底** | |
| **实习入职** | 已入职 | **12 月初** | |
| LeetCode 精选新题 | 约 150 | 12/20 | |
| LeetCode 复刷 / 模拟题次 | 约 70 | 12/20 | |
| 完成项目数 | 3 | 12/20 | |
| 项目 benchmark 数字齐全 | 3/3 | 12/20 | |
| 技术博客篇数 | 8 | 12/20 | |
| merged 开源 PR | 1–2 | 12/20 | |
| 累计投递（日常实习） | 40+ | 11 月中 | |
| 获得面试邀约 | 8+ | 11 月中 | |
| 完成面试场次 | 6+ | 11 月底 | |
| 题库勾选进度 | 80+ | 12/20 | |

加粗的两行是**硬约束**，其他指标都可以为它们让路。原因见 [roadmap.md 的倒推](roadmap.md#为什么日常实习必须-12-月前入职)：2 月底投暑期实习时实习时长要满两个月，才能进「开启即投」那一档。

**如果 11 月中「获得面试邀约」这一行还是 0**：立刻按 [roadmap.md](roadmap.md#风险与止损) 的止损方案执行——停下学习，两周全部投入简历重写 + 大规模内推 + 放宽岗位与地域。没有面试通常是简历叙事问题，不是能力问题。
